# Data Analytics Project

Overview

This project demonstrates an end-to-end data analytics workflow using Python, SQL, and Power BI. The goal of the project is to collect insights from raw data by performing data cleaning, exploratory data analysis (EDA), SQL-based analysis, and dashboard visualization.

The project also includes a professional report and presentation created using Gamma for clear business communication.

Dataset

The dataset used in this project contains structured data related to business/industry operations. It includes multiple attributes such as customer details, sales, transactions, performance metrics, or other relevant KPIs.


* Structured CSV/Excel dataset
* Missing values and duplicate handling
* Numerical and categorical columns
* Business-related metrics for analysis

Project Workflow

1. Data Loading

* Imported dataset using Python
* Checked dataset structure and data types
* Verified missing values and duplicates

2. Exploratory Data Analysis (EDA)

* Statistical summary of data
* Trend and distribution analysis
* Correlation analysis
* Visualizations using charts and graphs

3. Data Cleaning

* Removed duplicate records
* Handled null/missing values
* Standardized column names
* Converted data types where required

4. SQL Analysis

Performed SQL queries using:

* PostgreSQL
* SQL Server

Example SQL Operations

* Filtering and sorting data
* Aggregations using `GROUP BY`
* Joins between tables
* Window functions
* KPI calculations

 5. Dashboard Development

Built an interactive Power BI dashboard including:
* KPI cards
* Trend analysis charts
* Filters and slicers
* Category-wise performance analysis
* Business insights visualization

6. Reporting & Presentation
* Created a detailed analytics report
* Designed presentation slides using Gamma
* Summarized key findings and recommendations
